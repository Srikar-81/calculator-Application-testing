## Calculator Application — Manual Testing

Manual testing of a calculator application with structured test cases and input data.
Includes defect tracking and review reports for quality assurance documentation.

### What I did
- Designed and executed **70+ test cases** covering functional, UI, and regression scenarios following complete STLC from planning to closure
- Applied **BVA and ECP** techniques to maximize test coverage and minimize redundant scenarios
- Detected and documented **45+ defects** with severity and priority assignment
- Analysed FRS to derive test plan, test cases, test data matrix, and defect reports
- Tracked defects through a structured lifecycle ensuring no issues were missed during regression cycles
